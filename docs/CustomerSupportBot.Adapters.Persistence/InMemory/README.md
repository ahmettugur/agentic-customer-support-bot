# CustomerSupportBot.Adapters.Persistence.InMemory

Bu klasör, PostgreSQL veya Redis gibi harici altyapı bağımlılıkları olmadan uygulamanın çalışabilmesini, birim testlerin (Unit Tests) ve entegrasyon testlerinin hızlı koşabilmesini sağlayan bellek içi (InMemory) adaptörleri barındırır.

## Dosyalar

- [InMemoryAdapters](InMemoryAdapters.md) — Tüm bellek içi adaptörlerin (`InMemoryApprovalQueue`, `InMemorySessionManager`, `InMemoryReasoningTraceStore`, `InMemoryEscalationSink`, `InMemoryChatBridge`, `InMemoryMessageBusAdapter` vb.) detaylı teknik dökümü.
