# RealtimeNativeService

**Dosya:** `Services/Realtime/RealtimeNativeService.cs`

## 1. Ne İşe Yarar

SignalR üzerinden real-time mesaj push — chat mesajları, typing indicator, reasoning stream, approval/escalation bildirimleri.

## 2. Hangi Amaçla Kullanılır

Tüm real-time UI güncellemeleri bu servis üzerinden gönderilir. Chat ekranı, admin panel ve trace dashboard bu servise abone olur.
