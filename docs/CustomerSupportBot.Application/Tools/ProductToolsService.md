# ProductToolsService

**Dosya:** `Services/Tools/ProductToolsService.cs`

## 1. Ne İşe Yarar

Ürün domain tool'larını implement eder — ürün arama, ürün detay getirme, kategori listeleme.

## 2. Hangi Amaçla Kullanılır

`ProductAgent` bu tool'ları çağırır. Salt-okunur (read-only) tool'lar olduğu için HITL onay gerektirmez.
